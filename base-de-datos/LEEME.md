# Base de datos de SIGTA (copia)

`sigta.sql` es una copia de la base completa de SIGTA (tablas, reglas, triggers y datos iniciales), la misma que
está en el repositorio **SIGTA-Agrofood-Back** (`base-de-datos/sigta.sql`).

Las pantallas no usan este archivo: la base la usa la API. Está acá para tenerla a mano.
**La versión de referencia es la del Back**: ahí está también cómo importarla en Supabase
(`base-de-datos/LEEME.md`) y el comando para volver a generarla (`npm run db:exportar`).
